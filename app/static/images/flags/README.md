# Bandeiras das UFs nas etapas de entrega

Os arquivos `ro.svg`, `sc.svg`, `pr.svg`, `sp.svg`, `mg.svg`, `ba.svg`,
`pe.svg`, `mt.svg` e `go.svg` foram obtidos do projeto
[akagabi/bandeira-dos-estados-do-brasil](https://github.com/akagabi/bandeira-dos-estados-do-brasil),
distribuído sob licença MIT. O aviso de licença original está em
`LICENSE-akagabi.txt`.

`am.svg` foi obtido do [Wikimedia Commons](https://commons.wikimedia.org/wiki/File:Bandeira_do_Amazonas.svg)
em 27/10/2026. É a versão atualizada em julho de 2026, com 62 estrelas.
A página do arquivo informa domínio público e identifica o Governo do Amazonas
como autor.

Os arquivos são servidos localmente para que as bandeiras apareçam sem conexão
com serviços externos.
